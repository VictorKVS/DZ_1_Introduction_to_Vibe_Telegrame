# 01 — Requirements

> Требования к первой сквозной версии FATHER.

## Назначение

Раздел фиксирует проверяемые требования к первой вертикали FATHER до начала основной реализации. Требования должны трассироваться к архитектуре, решениям, тестам, рискам и фактическим результатам.

## Документы

- [SRS_V0_1.md](SRS_V0_1.md) — системные и функциональные требования первой вертикали.
- [NFR_V0_1.md](NFR_V0_1.md) — нефункциональные требования: ИБ, производительность, надёжность, наблюдаемость, стоимость и управляемость.

## Первая вертикаль

`Idea / Request → Evidence → Expert Review → SOCRATES-lite → Decision Record → Blueprint → Child Agent → Tests/Security → Outcome`

## Gate

Требования считаются готовыми к реализации, если:

1. каждое обязательное требование имеет ID;
2. для него указан критерий приёмки;
3. указано, каким тестом/метрикой оно будет проверяться;
4. ИБ-требования включены до написания кода;
5. нет критичного требования без владельца или Human Gate.
